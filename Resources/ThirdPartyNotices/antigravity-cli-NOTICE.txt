Codex Quota uses its Rust, Tokio and Serde implementation to read the official
agy CLI structured usage report. The implementation draws on CodexBar's report
format, identity separation, per-child update suppression and browser-launch
guard design. It does not use CodexBar's OAuth or multi-account implementation.

Windows background probing design reference:
https://github.com/hemsoft-dev/codexbar/pull/290
https://github.com/hemsoft-dev/codexbar/blob/66764b6f65964d1422e63aa5c575333b5bafb0e0/crates/codexbar-providers/src/gemini_coding.rs
The headless environment and single-process Windows Job design were consulted;
the Win32 calls and Tokio process management are independently implemented.
No source was copied and no dependency was added. Its MIT license follows below.

with Codex Quota. Authentication is handled by the CLI; this application does not
extract, copy or store Google credentials.
