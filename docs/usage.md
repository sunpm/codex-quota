# 使用说明

[返回 README](../README.md)

## 日常使用

侧栏包含用量、明细、额度和设置，切换菜单时页面与明细表滚动位置回到起点。界面跟随系统浅色 / 深色外观，数值使用等宽数字；用量和明细页顶部的总 Tokens 及模型、对话、项目汇总表的 Tokens 均显示带千位分隔符的完整数字，逐条明细的 Token 拆分保留简写、悬停查看完整值；“动画特性”与系统减少动态效果共同控制动效。选择框采用统一的细边框与箭头外观，保留系统选项菜单和键盘操作。

- **额度**：分别显示 Codex 与 Antigravity 实际返回的额度窗口、剩余百分比和本地倒计时；额度窗口采用双列布局，窄窗口改为单列，Codex 卡片同时包含重置卡与额度消耗趋势。顶部通过「全部」与 Codex / Antigravity 图标筛选额度卡片与公开重置动态；选择独立保存在本机，不影响用量页筛选或监测开关。进入额度页后台刷新已启用的服务；Codex 与 Antigravity 卡片各自提供刷新按钮和精确到秒的上次成功读取时间，读取中禁用按钮；默认每 1 分钟查询，共用不少于 30 秒的间隔。缺失额度显示未知，失败保留上次读数及成功时间并标明过期。启动、唤醒和重新开启监测会刷新，所有入口遵守服务端冷却时间。
- **用量**：顶部通过三张概览卡片展示总 Tokens（含新增输入、输出、缓存命中、缓存写入拆分）、API 等价估算费用及缓存命中率与活跃对话数；窄窗口自动折行。下方查看用量趋势、模型 / 项目 / 对话汇总和每日用量热力图；可按服务、时间与模型筛选。今天、昨天、最近 24 小时及不超过 24 小时的自定义范围使用小时趋势，较长范围使用每日趋势；跨日的小时刻度与提示保留日期。趋势图用「Tokens / 费用」切换指标；选择全部服务时，Codex 与 Antigravity 按固定颜色堆叠在同一时段的柱内。费用累计已定价记录，全部缺价时显示未定价空态；不同单位不会混在一根柱内。汇总表通过「模型 / 项目 / 对话」切换维度，对话视图按 Tokens 或费用表头排序即可查看高消耗对话。图表指标与表格排序独立。Tokens 与费用各自以“增减量（百分比）”显示同期对比，每项仅保留一个正负号，增加为红色加号、减少为绿色减号，悬停查看上期值；自然日筛选采用等长自然日范围，进行中的范围对齐当地截止时刻；最近 24 小时对比前一个 24 小时，自定义范围按所选时长前移比较。趋势图与热力图悬停同时显示 Tokens 与估算费用；热力图颜色深浅固定表示每日 Tokens 用量。
- **明细**：在同一页切换“按记录 / 按对话 / 按项目”，共用服务、日期与模型筛选，Tokens 和费用同时展示，汇总表支持 Tokens、费用、记录数、缓存命中率及最近用量的升降序排序；占比标明最近选择的 Tokens / 费用口径；切换视图时清空搜索词，表格滚动回到起点，筛选区、搜索框和表格外框高度保持稳定。按实际用量汇总，查看逐条时间、模型、Token 拆分、费用、计费档位及可确认的速度与首字估算。可确认的 Git worktree 归入主仓库，子模块独立；无法确认时保留原始目录。详情可选择复制完整会话 ID 与工作目录，展示主仓库映射、当前范围总量和多档位汇总；悬停费用查看精确值，拖动表头分隔线或聚焦后按左右方向键调整列宽。
- **设置**：分别管理 Codex / Antigravity 监测、公开动态通知与菜单栏 / 托盘显示，另有 Codex 恢复通知、额度重置前提醒、重置卡到期提醒及通用设置。Antigravity 默认关闭。“用量显示”直接列出已选指标与明细列，修改后立即更新。监测与托盘开关独立，用量分析不依赖监测开关。

服务筛选使用「全部」与 Codex / Antigravity 图标分段，悬停显示服务名，支持 Tab 和方向键；筛选在用量、明细和侧栏今日统计之间共享并保存在本机，切换服务重置模型选择；热力图只统计当前时间、服务与模型筛选内的记录，以至少 53 周的日历网格展示，较早的所选历史会扩展网格。模型和项目分组按服务分开，避免同名数据混淆。明细页记住当前视图、日期范围、模型、汇总排序字段、升降序、占比指标和搜索词，切换侧栏页面或重新打开应用后恢复；切换记录 / 对话 / 项目视图时清空搜索词。升级后沿用原对话页的筛选偏好。自然日范围随当前日期更新，自定义范围保留所选日期及时间。筛选偏好仅保存在本机，所选模型暂无记录时保留选择并显示空结果。悬停或用键盘聚焦“本机日志”旁的问号图标可查看统计范围，移出、失焦或按 Esc 关闭。

时间筛选按本地时区计算：“今天”为今日零点至当前，“昨天”为昨日零点至今日零点；“7 天”“30 天”分别从包含今天在内的第 7 / 30 个自然日零点起算。“最近 24 小时”从当前时刻向前滚动 24 小时，页面打开时随本地时钟每分钟推进，扫描或切换到该范围时也会更新，不额外请求服务。自定义范围通过原生日期时间控件选择开始与结束，精确到分钟，包含开始、不包含结束（例如 09:12—10:12 包含 09:12 的记录，不含 10:12 的记录）；不完整或结束不晚于开始时显示错误。升级时，旧版仅日期的自定义范围会将结束日期迁移为次日零点，保留原来包含结束日全天的口径。汇总、趋势、热力图、分组详情和记录列表共用同一时间范围；修改起止时间或切换筛选后回到第一页。

“按记录”列出当前服务、时间与模型范围内的逐条用量，可搜索会话标题、ID、项目或模型，翻页不改变顶部汇总。点击时间打开费用详情，对话与项目详情共用此入口；可选列直接在表格内配置并与设置同步，列宽保存在本机。

用量汇总、明细列表与逐条记录均支持分页，可选择每页 20 / 50 / 100 条、上一页 / 下一页及输入页码跳转。汇总表与逐条记录分别记住每页条数；更改筛选、排序、分组或每页条数后回到第一页。顶部总量和占比基数始终包含当前筛选的全部记录，不随翻页改变。逐条记录默认按时间降序，也可按各 Token 分项、费用和已显示的速度 / 首字排序；未定价或缺失数值始终排在末尾。

会话标题只读 `CODEX_HOME` 下的 `session_index.jsonl` 与 `state_5.sqlite` 元数据，状态数据库中的有效标题优先；支持 `config.toml` 的 `sqlite_home` 与 `CODEX_SQLITE_HOME`（配置优先）。标题随日志扫描刷新，仅在内存中保存与现有用量对应的标题，最多取 200 个字符；数据库中与首条消息相同的标题不作为会话标题读取。没有可用标题时显示项目名和短会话 ID，标题读取失败不影响用量计数；不读取或保存会话正文，不写入 Codex 数据库。

单条费用详情由 Rust 按当前有效价格计算，展示各 Token 分项、美元单价（每百万 Tokens）、已应用档位倍率的分项费用与合计，以及计价模型、档位、倍率和长上下文条件。与汇总共用同一 Decimal 计价实现，保留先合计再乘档位倍率的顺序；价格修改后按当前价格重新估算，不代表请求发生时的历史报价或订阅账单。未报告的 Token 分项显示“未报告 / —”，缺少必要用量、单价或倍率时总费用仍为“未定价”，不会将已知分项冒充完整费用。

Antigravity 费用拆分沿用其本地用量计价规则，不套用 Codex 档位倍率；模型未知、主要用量缺失或缓存写入时长无法确认时保持未定价。会话标题只匹配 Codex 记录；两项服务的明细均显示服务名，并使用各自的记录和模型信息。

启动恢复上次的窗口位置、尺寸与最大化状态，并显示主窗口。macOS Dock 图标跟随系统外观，`⌘0` 打开面板，系统菜单保留隐藏、缩放与前置全部窗口。

菜单栏 / 托盘可分别选择显示 Codex 与 Antigravity，菜单按服务逐桶列出额度与状态。macOS 紧凑标题中，Codex 优先显示 Codex 桶中按窗口时长排序的前两个值；Antigravity 显示最低的已知剩余额度。没有有效读数显示未知，不用 0% 代替。百分数使用系统等宽数字，图标保留完整轮廓，由系统与文字一起居中布局。菜单或悬停可查看窗口名称、剩余额度、当地重置时间与错误。

关闭窗口后继续监测，从菜单栏 / 托盘或应用入口重新打开同一窗口；退出应用才停止后台任务并清理本应用启动的子进程。macOS 有可用菜单栏入口时隐藏 Dock 图标，否则保留 Dock 入口。Windows 关闭后可从托盘或再次启动应用恢复窗口。

本机日志只在窗口可见时定期扫描，默认每 30 秒一次，也可手动刷新。右上角刷新按钮显示「刚刚刷新」或距上次扫描的分钟、小时、天数，悬停查看准确扫描时间。读取本地日志不发起模型请求。额度与公开重置动态各自独立调度，倒计时在本地计算。

Codex 额度趋势保留每个实测点，重置或观测中断处不连线，独立采样点也可见。悬停只读取附近的真实采样；空白时段显示“无采样”，不借用远处读数。Antigravity 首版不记录额度趋势。

Codex 额度倒计时与最早到期的有效重置卡倒计时共用时间分级：超过 24 小时为绿色，超过 6 小时至 24 小时为黄色，超过 1 小时至 6 小时为橙色，1 小时以内为红色。倒计时按剩余时长自适应精度与定时器频率：1 小时以内显示分秒并每秒更新，超过 1 小时至 1 天显示时分并每分钟更新，超过 1 天至 7 天显示天和小时并按小时更新，超过 7 天隐藏倒计时仅展示重置或到期日期。额度窗口的倒计时与绝对日期分列两端，空间不足时换行；重置卡的倒计时与到期日期整体靠右排列，卡片到期后移至下一张即将到期的卡；未知时间保持中性色。Codex 色阶随本地倒计时更新，Antigravity 首版的倒计时与重置日期统一使用中性色。

### Antigravity 额度

先安装独立的[官方 Antigravity CLI](https://github.com/google-antigravity/antigravity-cli)，在终端运行 `agy` 完成登录。macOS 要求正式版 1.1.11 或更新；Windows 要求原生 `agy.exe` 正式版 1.4.10 或更新，以使用已核对的非交互认证行为。不自动连接 WSL，也不从 Antigravity 桌面程序提取登录信息。

Antigravity 默认关闭，额度页选择“全部”时，首次成功读取额度报告前不显示其卡片；单独选择“Antigravity”时始终显示卡片，无读数时提示读取中、登录要求或暂无数据，并显示监测关闭或查询错误状态。在设置中开启监测后，尚无读数时会显示读取状态或具体错误，并提供安装说明和“重新读取”入口；关闭监测后隐藏设置中的这些提示。成功读取后显示实际额度，后续刷新失败仍保留旧读数并标记过期。

应用调用 `agy -p /usage --output-format json`，由 CLI 处理认证与网络请求。按报告中的分组名称、桶 ID 和名称展示，新增模型组无需固定映射；只有明确的 `5h`、`weekly` 窗口分别显示“五小时额度”“周额度”，其他情况显示“额度”。服务明确禁用的桶显示“未启用”，缺失或超出有效范围的剩余额度显示“未知”，缺失或无效重置时间也保持未知；倒计时归零不会把额度改为满额。

关闭 Antigravity 桌面界面后，只要独立 CLI 已安装、登录存储可访问且网络正常，就不需要保持界面运行。首次查询可能需要等待 CLI 完成认证。应用只为自己启动的进程禁用自动更新，不修改用户全局设置；后台不会主动引导登录，明确需要登录、CLI 版本不兼容等问题时暂停自动重试。请在终端处理后，在设置中点击“重新读取”；已有额度卡片时，也可在卡片上点击“刷新”。网络失败、原因未明的查询失败或超时会自动重试，失败期间保留本次运行中上一次成功数据并标明过期。

CLI 报告没有可靠账号身份，首版不显示账号归属、不保存 Antigravity 额度历史或发送个人恢复提醒；不能据相邻读数认定来自同一账号。切换 CLI 账号后请手动刷新；本应用不管理或自动切换账号。本地用量另行只读扫描，不以当前登录账号划分。

Windows 后台查询使用不带终端的受限进程，禁止启动浏览器及其他子进程，因此配置了 MCP 或外部辅助程序的 CLI 可能查询失败。macOS 为查询设置独立进程会话并拦截浏览器启动命令。当前实机验收结果与平台限制见[开发说明](development.md)。

自定义位置可通过 `CODEX_QUOTA_AGY` 指定官方 CLI 可执行文件；该变量一旦设置便优先采用，路径无效时直接提示。否则从 `PATH`、用户的 `~/.local/bin` 及平台常见安装目录查找。macOS 从 Finder 启动时可能无法继承终端自定义的 `PATH`。

### 提醒与公开动态

macOS 通知使用系统通知中心，应用在前台时也会显示提醒；设置页区分持续提醒、临时横幅、已授权但未开启桌面提醒及无法确认的样式，从系统设置返回后刷新。首次允许通知后，若尚未开启持续提醒，会展示一次设置引导；沿用旧版已显示记录，也可从“持久通知…”手动打开。已开启持续通知时隐藏该入口。测试通知与自动提醒使用同一发送通道，发送失败会保留错误提示。未打包的开发进程不能测试 macOS 通知，请使用应用包。

个人额度提醒目前只用于 Codex。恢复通知只依据同一账号、同一额度窗口的真实用量从非零恢复到零触发；启动时已满额、显示舍入和倒计时归零均不会触发。通知按账号与窗口跨重启去重，关闭通知期间仍更新基线，重新开启不会补发旧事件。两次轮询之间发生且已再次消耗的恢复可能无法观察到。

重置卡到期提醒与额度重置前提醒分别设置，默认关闭。开启后可按天、小时或分钟添加、编辑和删除提前时间，例如提前 1 天、5 小时和 2 小时；每个有效时间点最多提醒一次，相同时间不能重复。重置卡默认提前 1 天，兼容已有开关与提醒记录；额度默认提前 2 小时。额度提醒仅在接口返回明确的未来重置时间且仍有剩余额度时发送，通知包含额度窗口、剩余百分比与重置时间；提前时间须短于对应额度窗口时长。

两类提醒都在成功刷新后检查，实际提醒时间受刷新间隔、休眠和网络状态影响；应用退出后不发送。每个时间点按账号、卡片或额度窗口及对应到期 / 重置时间跨重启去重。错过多个时间点时，同一张卡或同一窗口只提醒当前最近的一次；同次刷新的多张卡或多个窗口合并通知。关闭通知期间仍更新记录，重新开启不补发已观测到的旧提醒；失败或过期数据不触发。重置卡仅提醒仍可用且有到期明细的卡，不推测缺失信息。卡片到期标识随本地时间更新；可用数量仍以接口快照为准，不由本地推算改写。应用不使用重置卡。

额度页展示 AIHOT 的 [Codex](https://aihot.news/codex-reset) 与 [Antigravity](https://aihot.news/antigravity-reset) 公开重置动态：选择「全部」时按更新时间合并展示最近四条，并标注所属服务；单独选择服务时显示对应的最近三条。两项服务各自约每 10 分钟查询并独立遵守缓存与 `Retry-After`。动态展示适用范围，以“预告”和“AIHOT 估计”区分时间来源。公告不表示当前账号已经恢复，不改写个人额度或倒计时，也不触发个人恢复提醒。预告过期后仍需确认，两项服务的首次读取分别建立通知基线，关闭通知期间继续更新，重新开启不会补发旧事件。数据使用遵循 [AIHOT 使用条款](https://aihot.news/terms)。

应用包含当前版本更新说明时，该版本首次打开会展示，关闭后保存已读版本。设置中的新版说明与首次展示共用 Markdown 排版，支持标题、列表、链接和折叠说明，自动隐藏 GitHub 生成的注释；没有随包说明的本地构建不显示空弹窗。

## 统计口径与数据

使用自定义路径时，可通过环境变量 `CODEX_QUOTA_CLI` 指定 CLI 可执行文件，通过 `CODEX_HOME` 指定 Codex 数据根目录。

默认读取 `~/.codex/sessions` 和 `~/.codex/archived_sessions`，Windows 的 `~` 为当前用户目录。支持 `.jsonl` 与 `.jsonl.zst`，压缩日志按块解码，不生成解压文件。

- 按日志中的 `last_token_usage` 统计，使用累计签名去重；普通 / 压缩副本、归档迁移、分段和 fork 重放不会重复计数。缺少逐次用量的旧事件不从累计值倒推。
- 总 Tokens = 新增输入 + 输出 + 缓存命中 + 缓存写入。输入已扣除缓存，不重复加上推理 Token。缓存命中率分母为全部输入（含缓存），分母为零显示不可用。
- 费用以 Rust `Decimal` 逐项计算，是美元 API 等价估算，**不代表订阅账单**。价格未知与真实零价分开；汇总仅累加已定价记录，统一显示“估算费用”；部分缺价时该金额不代表完整费用，完全缺价显示“未定价”。费用占比按已定价金额计算；Tokens 占比按全部已知计数计算。
- 内置 [OpenAI](https://developers.openai.com/api/docs/pricing)、[Google](https://ai.google.dev/gemini-api/docs/pricing) 与 [Anthropic](https://platform.claude.com/docs/en/about-claude/pricing) 官方文字 Token 价格快照。“更新官方价格”直接读取三方官方文档，全部读取成功后更新两项服务的价格；失败保留旧价格，自定义价格不被覆盖。Google 使用付费 Standard 单价，按更新日期选择官方公布的促销价，不把免费层、Batch、缓存存储或工具费用混入 Token 单价；促销到期后需重新更新。旧目录保留用于官方当前页面未列出的历史模型。
- 定价列表合并日志模型，优先展示含未定价记录和有用量的模型，可筛选“有用量 / 含未定价 / 自定义”，未定价记录数基于全部已采集历史。已有模型名称只读；新增同名模型会提示返回编辑。移除自定义后回到公开价格，无公开价格且无日志引用的模型从列表移除。日志未提供模型名称时不能通过设置 `unknown` 价格补算。
- 只匹配已确认模型标识，不按 tiered、trial、high 等后缀猜测价目。空白表示未知，`0` 表示免费；标准价、速度倍率和长上下文单独编辑，清空阈值即取消长上下文分档。价格变更重新计算历史，不保存价格版本。
- 长上下文单价按单条请求全部输入（含缓存）判定，只有超过阈值才切换。Codex 明确报告的 30 分钟 / 12 小时缓存写入分项分别计费，不重复加入总写入数；分项与总数冲突的记录不纳入统计。Fast / Ultrafast 倍率只从官方各 Token 单价及长上下文档位的一致比例得到，不能用一个倍率表达时保持未知，可手动设置。Codex 未知计费档位不按 Standard 猜测；缺少档位的旧记录按 Standard 估算；没有明确报告来源时，包括旧历史字段缺失或 null，均显示“Standard（估算）”。
- 速度与首字为日志边界估算，带 `≈`；缺少可靠依据显示 `—`。缓存写入缺失不伪装成零。记录数指解析出的用量事件数，不代表全部网络请求数。

本机统计包含现存日志与已采集历史，可能包含多个账号，不代表当前账号或其他设备的全部用量。应用只保存统计所需元数据，不保存消息正文、浏览器 Cookie 或登录 token。

| 平台 | 应用数据目录 |
| --- | --- |
| macOS | `~/Library/Application Support/CodexQuotaDock/` |
| Windows | `%APPDATA%\CodexQuotaDock\` |

`usage-history.json` 沿用旧版格式，采集与展示 Codex 和本轮原生导入的 Antigravity 记录。旧版 Antigravity 记录保留但不自动纳入新统计；可读取源数据会重新导入，界面提示旧记录数量。其他服务旧历史保留但不展示。设置、Codex 额度趋势、通知基线及冷却时间保存在同一应用数据目录中。Antigravity 个人额度只保留在当前运行的内存中；其公开动态缓存、通知基线与监测偏好独立保存，使用新的 `antigravity.cli.*` 设置键，不启用旧版接入或凭据。读取损坏或未知版本的数据时保留原文件并提示，不按空数据覆盖。

在设置的“用量历史”选择 Codex 或 Antigravity。“重新扫描”只清空该服务的内存扫描缓存，保留已保存历史；“清除已保存历史”经确认后清除本应用保存的所选服务记录（Antigravity 包括未纳入统计的旧版记录），随后重新采集仍在本机的记录。不删除源日志、其他服务历史或模型价格。


### Antigravity 本地历史

扫描 `~/.gemini/antigravity-cli/` 和 `~/.gemini/antigravity/`；Windows 的 `~` 为当前用户目录。`GEMINI_CLI_HOME` 可指定替代 `.gemini` 的绝对路径，只影响本地用量，不改变额度查询或登录态。

- JSONL：读取 `brain/<会话>/.system_generated/logs/transcript_full.jsonl` 中已完成的 `PLANNER_RESPONSE`，使用 `step_index`、`created_at` 和真实 Token 计数。不要求状态栏脚本或 hook。
- SQLite：只读 `conversations/<会话>.db`（兼容桌面根目录的 `<会话>.db`），关联 `steps` 与 `gen_metadata`，补全模型、计数和计时；项目取 `trajectory_metadata_blob` 中唯一可确认的工作目录。多目录无法唯一归属时保留未知项目。
- 输入不含缓存读取，输出已经包含思考 Token，因此不再扣缓存或累加思考。缺少分类的记录只显示已知计数，费用保持未知；字段缺失与真实 `0` 分开。缓存写入、首字、速度和计费档位没有可靠来源时显示 `—` 或未知。
- 时间只使用响应时间或对应原生步骤时间，不用文件修改时间、会话创建时间代替。未知时间或未知格式提示未覆盖，不计作零。
- 同一会话跨 CLI / 桌面目录按真实步骤或生成索引去重；纯索引不遮蔽日志。文件变化后重读该会话，修正被更新的步骤；子代理只计自身生成记录，不叠加父会话中的汇总或消息转发。
- 有真实计数的 JSONL / SQLite 可导入安装本应用前的保留记录。旧加密 `.pb`、不支持布局及无法读取的数据显示覆盖提示，不解密、不导出本地服务、不承诺恢复全部历史。

Antigravity 本地统计不要求额度监测或官方界面持续运行，可能包含多个账号。它表示本机可读取历史，不代表当前账号或其他设备的全部消耗。API 等价估算使用公开文字 Token 的基准单价，不推断 Antigravity 的计费档位、地区或缓存写入时长；有缓存写入计数但无法确认时长时费用保持未知。它不是订阅账单、额度扣减或工具附加费；未知模型与未知价格不会显示为免费。价格更新会重算已保存记录，当前不保存历史价格版本。
